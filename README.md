🎮 Game Sense: Esports Performance & Gaming Health Analytics

📌 Project Overview

Game Sense is a data analytics project that explores esports gaming performance and player health. It analyzes gaming habits and health-related factors to identify patterns that may be associated with player performance.

🎯 Project Objectives

- Analyze esports gaming performance.
- Understand the relationship between sleep and reaction time.
- Explore APM and win-rate patterns.
- Study heart rate and HRV.
- Create meaningful visualizations and a Power BI dashboard.

📊 Dataset Information

- Dataset: Esports Gaming Biometrics Dataset
- Source: Kaggle
- Records: 250,000 rows
- Original columns: 13
- Columns after feature engineering: 16
- Dataset Availability: The complete raw dataset is included in this repository. A sample of 10,000 rows from the cleaned dataset is provided for demonstration due to file size limitations. The complete cleaned dataset is retained separately.

🛠️ Tools & Technologies

- Power BI

⚙️ Project Workflow

1. Data collection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature engineering
5. Data visualization
6. Power BI dashboard development
7. Insights and conclusions

🔍 Key Findings

- Players with longer sleep durations showed better average reaction times.
- The 220–250 ms reaction-time group recorded the highest win rate.
- The 100–200 APM group had a lower win rate than the other APM groups.
- Heart rate increased with higher energy drink consumption in the dataset.
- Blue-light filter usage was observed among approximately 65% of players.

Note: These findings show patterns in the dataset and do not establish cause-and-effect relationships.

📈 Dashboard

The Power BI dashboard presents insights into gaming performance, player health, sleep patterns, reaction time, and other gaming habits.
